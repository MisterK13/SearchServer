# 🔍 SearchServer - Многопоточный поисковый движок

Высокопроизводительный поисковый движок с поддержкой многопоточности, реализованный на C++20. Проект демонстрирует современные подходы к многопоточному программированию, включая read-write locks, пулы потоков и асинхронную обработку запросов.

## ✨ Особенности

- **Многопоточный поиск** - параллельная обработка запросов с использованием пула потоков
- **Read-Write Lock** - оптимизированная синхронизация с разделяемыми блокировками
- **TF-IDF ранжирование** - качественная релевантность документов
- **Поддержка минус-слов** - исключение документов из результатов
- **Фильтрация по статусу** - ACTUAL, IRRELEVANT, BANNED, REMOVED
- **История запросов** - отслеживание последних запросов в RequestQueue

### Требования
- Компилятор с поддержкой C++20 (GCC 11+, Clang 14+, MSVC 2022)
- CMake 3.15+ (опционально)

### Компиляция

```bash
# Клонирование репозитория
git clone https://github.com/yourusername/SearchServer.git
cd SearchServer

# Компиляция (ручная)
g++ -std=c++20 -pthread -O2 \
    src/*.cpp \
    examples/main.cpp \
    -o search_server.exe

# Запуск
./search_server.exe
